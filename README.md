## `ABOUT / ABDUL`

I'm Abdul Muhaymin Nawaz, Founder & CTO of [The Technostic Group](https://technosticsgroup.com/).

I work across **cybersecurity, artificial intelligence, software engineering, systems design, and experimental computing**—turning difficult ideas into practical systems and investigating the weaknesses that appear along the way.

My interests include defensive security engineering, application security, intelligent detection, AI-assisted workflows, custom firmware, developer tooling, and human-computer interfaces.

I am particularly interested in technology that is:

- **Proactive** instead of reactive
- **Explainable** instead of opaque
- **Secure by design** instead of secured as an afterthought
- **Useful in the real world** instead of impressive only in a demo

> Every system has assumptions.  
> Every assumption creates an attack surface.
